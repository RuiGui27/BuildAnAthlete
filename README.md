# BuildAnAthlete

BuildAnAthlete is a workout planning and tracking app for organizing training sessions, managing an exercise dictionary, and reviewing workout history over time. It includes a calendar, workout notes, and calculators for strength and jump-performance metrics. Built for desktop and mobile, with Android support through Capacitor.
Although it is not yet complete, as I intend to add a menu for creating and managing athletes, and for tracking their progress across all metrics and exercises, complete with charts for analyzing every detail.
